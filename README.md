# Comunicaciones Narváez

Página web de ventas para productos de celulares y tecnología.

## Descripción

Sitio estático para presentar catálogo, promociones y contacto de una tienda tecnológica llamada **Comunicaciones Narváez**.

## Archivos principales

- `index.html`: estructura de la página
- `styles.css`: estilos visuales del sitio
- `script.js`: catálogo interactivo y filtros

## Cómo abrirlo

1. Abre la carpeta del proyecto en Visual Studio Code.
2. Haz clic derecho en `index.html`.
3. Selecciona "Open with Live Server" o abre el archivo en tu navegador.

## Personalización

Puedes modificar:
- nombres de productos
- precios
- colores
- textos de oferta
- información de contacto

## Tecnologías usadas

- HTML5
- CSS3
- JavaScript vanilla
